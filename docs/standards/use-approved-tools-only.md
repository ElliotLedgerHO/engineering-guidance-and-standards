Teams only use tools that are approved for the use case. A tool is any software, platform or service that teams use to build, run or support a product or service, including artificial intelligence (AI) tools, models and extensions.

---

## Requirement(s)

- [Tool and use case MUST be on the Technology Register](#tool-and-use-case-must-be-on-the-technology-register)
- [New tools, use cases and extensions MUST be approved at TDA](#new-tools-use-cases-and-extensions-must-be-approved-at-tda)

### Tool and use case MUST be on the Technology Register

Teams must only use a tool for a use case listed against it on the [Technology Register](https://technology-register-dev.cto-notprod.homeoffice.gov.uk).

This includes AI tools and their extensions.

### New tools, use cases, and extensions MUST be approved at TDA

Teams must take any of the following to the Technical Design Authority (TDA) for approval before use:

- a new tool not currently on the Technology Register
- a new use case for an approved tool
- a new extension – any add-on that connects an approved tool to more capabilities, data or systems, such as plugins or integrations

For AI, teams must also take the following to TDA:

- a new AI model family not yet on the Technology Register
- a new Model Context Protocol (MCP) server or other AI extension

TDA must record decisions on the Technology Register so it stays the single source of truth.
